# Contributing

Contributions that keep the starter small, inspectable and evidence-first are welcome.

1. Open an issue describing the change and the civic question it supports.
2. Use fictional or openly licensed sample data only.
3. Preserve source labels and explicit evidence limits.
4. Add or update tests for graph rules and claim boundaries.
5. Run `npm test` before opening a pull request.

Do not submit credentials, personal information, production data or copied proprietary prompts.
